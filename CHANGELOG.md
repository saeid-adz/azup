# Changelog

## 2.2.0
- Linux: PowerShell is now installed from Microsoft's official release tarball into `~/.local` – no snap, no sudo, SHA-256 verified, updatable with `azup update`.
- A tool found on PATH that doesn't even start (e.g. a broken snap `pwsh`) is treated as not installed, so azup can replace it.

## 2.1.2
- Homebrew: if a package ends up "installed but not linked" (e.g. after the tap-trust retry), azup now runs `brew link` so the command actually works.
- PowerShell: azup smoke-tests `pwsh` before installing modules. If it doesn't start, you get one clear explanation (with diagnostics to run) instead of one cryptic failure per module.

## 2.1.1
- Azzy is now an Azure-style "A" with eyes (light left half, dark right half) in the terminal, README demo and banner.

## 2.1.0
- Animations: shimmering gradient banner, **Azzy** the mascot (blinking eyes, jokes while loading, Clippy-style suggestions that pre-select the right menu row), progress bars and a confetti finish. Off with `--no-anim`, `AZUP_NO_ANIM=1`, `NO_COLOR` or when output is piped.
- New `azup joke`.
- New README with animated banner and demo (SVGs generated by `assets/make_assets.py`).

## 2.0.3
- Fix `azup self-update` always reporting "REPO is not configured".

## 2.0.2
- Linux: authenticate `sudo` before the non-interactive Homebrew installer; clear errors for root / missing sudo / missing build tools.

## 2.0.1
- Handle Homebrew untrusted-tap errors: explain, offer to run `brew trust …`, retry once.

## 2.0.0
- First public release: Windows, macOS, Linux; checklist menu; status/install/update/doctor/login/self-update; one-line installers.
