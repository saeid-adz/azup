# Code of Conduct

We want azup to be a friendly place for everyone who works with Azure, whatever their experience.

**Expected:** be kind and patient, assume good intent, give and accept feedback gracefully, and keep
discussion about the work.

**Not acceptable:** harassment, discrimination, personal attacks, trolling, publishing other people's
private information, or anything you wouldn't say to a colleague.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block
repeat offenders. To report a problem, use the private reporting form in the repository's Security tab
(<https://github.com/saeid-adz/azup/security/advisories/new>) and mention it's a conduct concern.

This is a short, plain-language code of conduct inspired by the
[Contributor Covenant](https://www.contributor-covenant.org/).
